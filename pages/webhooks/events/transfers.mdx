Os eventos `transfer.*` avisam o resultado de um [envio de Pix](/pages/dinheiro/enviar-pix) do seu saldo para outra pessoa ou empresa, feito pela API ou pelo dashboard em **Financeiro → Pagamentos**. O saque para a conta bancária da loja usa os eventos de [saque](/pages/webhooks/events/payouts). A entrega, as retentativas e a verificação estão em [Webhooks](/pages/notificacoes/webhooks).

| Evento | Quando dispara |
|---|---|
| `transfer.completed` | O Pix é concluído, e o dinheiro chega ao destino. |
| `transfer.failed` | O Pix falha, e o valor volta para o saldo. |

Envios de Pix não existem no [Modo Teste](/pages/comecar/modo-teste), então esses eventos só chegam em produção.

## Campos

| Campo | Tipo | Descrição |
|---|---|---|
| `data.transfer.id` | `string` | ID do envio (`tran_...`). |
| `data.transfer.externalId` | `string \| null` | O identificador que você enviou ao fazer o Pix pela API. Use para achar o envio no seu sistema. |
| `data.transfer.amount` | `number` | Valor enviado, em centavos. |
| `data.transfer.status` | `string` | `COMPLETE` no `transfer.completed` e `FAILED` no `transfer.failed`. |
| `data.transfer.method` | `string` | `PIX`. |
| `data.transfer.platformFee` | `number` | Taxa do envio, em centavos. |
| `data.transfer.receiptUrl` | `string` | Link do comprovante. |
| `data.transfer.createdAt` | `string` | Quando o envio foi pedido (ISO 8601). |
| `data.transfer.updatedAt` | `string` | A última mudança de status (ISO 8601). |
| `data.transfer.endToEndIdentifier` | `string \| null` | Identificador do Pix no Banco Central. O campo sempre vem, com `null` quando não há identificador, como num envio que falhou. |
