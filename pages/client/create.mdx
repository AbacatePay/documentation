---
title: 'Criar um Cliente'
openapi: "POST /customers/create"
---

Cadastra um cliente para cobrar sem pedir os dados de novo no checkout. Se o cliente já existe, devolve o cadastro existente atualizado.

<Card horizontal>
  Requer a permissão `CUSTOMER:CREATE`.
</Card>

<Card title="Entenda os clientes" icon="users" href="/pages/vender/clientes" horizontal>
  Campos, como a AbacatePay evita duplicados e quando o checkout pula a etapa de dados.
</Card>

Só `email` é obrigatório, e o corpo é plano (sem `data`).

**Exemplo mínimo:**
```json
{
  "email": "joao@exemplo.com"
}
```

**Exemplo completo:**
```json
{
  "email": "joao@exemplo.com",
  "name": "João Silva",
  "taxId": "11144477735",
  "cellphone": "11999999999",
  "zipCode": "01310100",
  "address": {
    "zipCode": "01310100",
    "street": "Avenida Paulista",
    "number": "1000",
    "neighborhood": "Bela Vista",
    "city": "São Paulo",
    "state": "SP",
    "complement": "Sala 12"
  },
  "metadata": { "plano": "premium" }
}
```

## Erros

| Mensagem em `error` | Quando acontece |
|---|---|
| `email must be a valid email` | `email` inválido. |
| `Invalid taxId` | CPF ou CNPJ inválido. |
| `Invalid zipCode` | `zipCode` sem 8 dígitos. |
| `Invalid address.zipCode` | `address.zipCode` sem 8 dígitos. |
| `address.state must be 2 characters long` | `address.state` sem 2 letras. |
