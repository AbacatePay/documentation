Com **payouts** você saca o saldo da conta de forma automatizada para uma chave PIX de sua titularidade.

## Estrutura

Exemplo de resposta de um saque:

```json
{
  "data": {
    "id": "tran_abc123xyz",
    "status": "COMPLETE",
    "devMode": false,
    "receiptUrl": "https://app.abacatepay.com/receipt/tran_abc123xyz",
    "amount": 10000,
    "platformFee": 80,
    "externalId": "saque-123",
    "createdAt": "2024-11-04T18:38:28.573Z",
    "updatedAt": "2024-11-04T18:38:28.573Z"
  },
  "success": true,
  "error": null
}
```

## Atributos

| Atributo     | Tipo    | Descrição |
| ------------ | ------- | --------- |
| `id`         | string  | ID único da transação na AbacatePay |
| `status`     | string  | Status do saque (veja valores abaixo) |
| `devMode`    | boolean | `true` se criado em sandbox |
| `receiptUrl` | string \| null | URL do comprovante; disponível quando `status` é `COMPLETE` |
| `amount`     | number  | Valor debitado do seu saldo, em centavos (ex.: 10000 = R$ 100,00) |
| `platformFee` | number | Taxa da plataforma em centavos, descontada do `amount` |
| `externalId` | string  | ID no seu sistema |
| `createdAt`  | string  | Data/hora de criação (ISO 8601) |
| `updatedAt`  | string  | Data/hora da última atualização |

**Valores de `status`:**

| Valor        | Significado |
| ------------ | ----------- |
| `COMPLETE`   | Saque aceito pelo provedor. Todo saque já é criado com esse status. |
| `FAILED`     | O provedor recusou o envio depois de aceito. O valor volta para o seu saldo. |

<Warning>
  `COMPLETE` na criação não garante que o dinheiro chegou: o saque ainda pode passar para `FAILED`. Use os webhooks para confirmar o resultado: `payout.completed` e `payout.failed`, ou `transfer.completed` e `transfer.failed` quando o saque foi criado com `externalId` (veja [Eventos de saques](/pages/webhooks/events/payouts)).
</Warning>

## Limites e taxas

- **Mínimo:** R$ 3,50 (350 centavos)
- **Taxa:** R$ 0,80 por saque dentro dos limites; ver [termos de uso](https://abacatepay.com/termos). A taxa é descontada do `amount`: num saque de R$ 100,00, chegam R$ 99,20 na chave de destino, e o seu saldo precisa cobrir os R$ 100,00.
- **Processamento:** instantâneo; 24/7 respeitando limites diários e noturnos da conta
- **Limite:** 1 saque por minuto; excesso retorna HTTP 429. Para aumentar, fale com o suporte

## Segurança

- Requisições autenticadas via Bearer Token
- Abusos podem levar à suspensão da conta conforme os [termos de uso](https://abacatepay.com/termos)
