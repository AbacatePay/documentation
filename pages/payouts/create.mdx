---
title: Criar um Saque
openapi: 'POST /payouts/create'
---

Saca o saldo disponível da sua conta por Pix para uma chave no mesmo CPF ou CNPJ da conta.

<Card horizontal>
  Requer a permissão `WITHDRAW:CREATE`.
</Card>

<Card title="Entenda os saques" icon="money-bill-transfer" href="/pages/dinheiro/saques" horizontal>
  Mínimo de R$ 3,50, taxa, saldo de origem, limites diário e noturno, intervalo de 30 segundos, idempotência pelo `externalId` e eventos.
</Card>

**Exemplo:**
```json
{
  "amount": 10000,
  "externalId": "saque-2026-11-10",
  "pix": {
    "key": "12345678000190",
    "type": "CNPJ"
  }
}
```

**Erros comuns:**

| `error` | Motivo |
|---|---|
| `Property 'pix' is missing` | O destino não veio em `pix`. Mandar `pixKey` e `pixKeyType` no topo cai aqui |
| `Property 'pix.type' is missing` | `pix` veio sem `type` e `key`, por exemplo com `pixKey` e `pixKeyType` dentro dele |
| `externalId já usado em outro envio com valor diferente` | Já existe um saque ou envio de Pix com esse `externalId` e outro `amount` |
| `externalId já usado em um envio de outro saldo (da loja ou de outra subconta)` | O `externalId` já foi usado no saque de uma subconta |
| `Saldo insuficiente` | O `amount` passa do saldo disponível, já descontado o débito de disputa em aberto |
| `Não é possível sacar os saldos de PIX e cartão no mesmo saque` | Nenhum dos dois saldos cobre o valor sozinho |
| `Essa chave Pix não está em nome da sua empresa. Para enviar a outra pessoa ou empresa, inclusive sócios, use a tela Pagamentos.` | A chave é de outro CPF ou CNPJ. Para pagar outra pessoa, use [Enviar Pix](/pages/pix/create) |
| `Chave PIX não encontrada` | A chave não existe |
| `Aguarde alguns segundos antes de solicitar outro saque` | A conta fez um saque ou um envio de Pix há menos de 30 segundos |
| `Limite de saque diário atingido` | O saque passaria do limite diário da conta |
| `Limite de saque noturno atingido` | Das 20h às 8h, o saque passaria do limite noturno da conta |
| `Saques estão temporariamente indisponíveis. Tente novamente mais tarde.` | Os saques estão em manutenção |
| `Função não habilitada` | O saque pela API está desativado na sua conta |
