---
title: 'Criar um produto'
openapi: "POST /products/create"
---

Cria um produto no seu catálogo para usar em checkouts, links de pagamento e assinaturas.

<Card horizontal>
  Requer a permissão `PRODUCT:CREATE`.
</Card>

<Card title="Entenda os produtos" icon="box" href="/pages/vender/produtos" horizontal>
  Avulso ou assinatura, preço, `externalId`, imagem, arquivo para download e período de teste.
</Card>

**Produto avulso:**
```json
{
  "externalId": "camiseta-premium",
  "name": "Camiseta Premium",
  "price": 8990,
  "currency": "BRL",
  "description": "Camiseta 100% algodão"
}
```

**Produto de assinatura com 7 dias grátis:**
```json
{
  "externalId": "plano-mensal",
  "name": "Plano Mensal",
  "price": 4990,
  "currency": "BRL",
  "cycle": "MONTHLY",
  "trialDays": 7
}
```

**Produto com arquivo para download:**
```json
{
  "externalId": "ebook-guia",
  "name": "E-book: Guia Completo",
  "price": 2990,
  "currency": "BRL",
  "fileUrl": "https://exemplo.com/guia-completo.pdf"
}
```

## Erros

| Mensagem em `error` | Quando acontece |
|---|---|
| `Product with externalId already exists` | Já existe um produto com esse `externalId` na loja. |
| `price must be at least 1` | `price` menor que 1 centavo. |
| `trialDays must be between 1 and 90` | `trialDays` fora do intervalo. |
| `Failed to fetch image from the provided URL` | A AbacatePay não conseguiu baixar o `imageUrl`. |
| `The provided URL does not point to a valid image` | O `imageUrl` não é PNG, JPEG, GIF nem WebP. |
| `Image size exceeds the 5MB limit` | A imagem passa de 5 MB. |
| `Failed to fetch file from the provided URL` | A AbacatePay não conseguiu baixar o `fileUrl`. |
| `The provided URL does not point to a valid PDF file` | O `fileUrl` não é um PDF. |
| `File size exceeds the 20MB limit` | O PDF passa de 20 MB. |
