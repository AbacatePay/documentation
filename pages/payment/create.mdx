---

Cria um checkout: uma página de pagamento hospedada pela AbacatePay, que aceita um pagamento. Você envia os produtos e a API devolve a `url` para mandar ao cliente.

<Card horizontal>
  Requer a permissão `CHECKOUT:CREATE`.
</Card>

<Card title="Entenda o checkout" icon="book-open" href="/pages/cobrar/checkout" horizontal>
  Regras, valor mínimo, status, formas de pagamento e personalização da página.
</Card>

**Exemplo mínimo:**
```json
{
  "items": [
    { "id": "prod_abc123xyz", "quantity": 1 }
  ]
}
```

**Exemplo completo:**
```json
{
  "items": [
    { "id": "prod_abc123xyz", "quantity": 1 }
  ],
  "customerId": "cust_abc123xyz",
  "externalId": "pedido-123",
  "returnUrl": "https://seusite.com/carrinho",
  "completionUrl": "https://seusite.com/obrigado",
  "methods": ["PIX", "CARD"],
  "card": {
    "maxInstallments": 3
  },
  "coupons": ["PROMO10"],
  "metadata": { "origem": "app-mobile" }
}
```

**Exemplo com [upsell](/pages/vender/upsell):**
```json
{
  "items": [
    { "id": "prod_abc123xyz", "quantity": 1 }
  ],
  "upSellProductId": "prod_bump456xyz"
}
```

**Exemplo com [boleto, vencimento, juros e multa](/pages/pagamentos/juros-e-multa-boleto):**
```json
{
  "methods": ["BOLETO"],
  "dueDate": "2026-12-15",
  "items": [
    { "id": "prod_abc123xyz", "quantity": 1 }
  ],
  "interest": { "value": 100 },
  "fine": { "value": 200, "type": "PERCENTAGE" }
}
```

## Erros

| Erro | Motivo |
|---|---|
| `Product prod_... not found` | Um dos itens não existe na sua loja. `items[].id` aceita o `id` ou o `externalId` do produto. |
| `Total price must be at least 100 cents` | O total ficou abaixo de R$ 1,00. |
| `O valor mínimo para boleto é R$ 3,00 (300 centavos)` | Com `BOLETO` em `methods`, o total precisa ser de pelo menos R$ 3,00. |
| `At least one payment method is required` | `methods` veio vazio. |
| `PIX is not available for this store` | A forma de pagamento não está liberada na sua conta. Vale também para `CARD` e `BOLETO`. |
| `Customer not found` | O `customerId` não existe na sua loja. |
| `Could not find coupons PROMO10` | Um dos códigos de `coupons` não existe na sua loja. |
| `interest/fine requires BOLETO in methods` | `interest` e `fine` só valem com `BOLETO` em `methods`. |
| `dueDate requires BOLETO in methods` | `dueDate` só vale com `BOLETO` em `methods`. |
| `card.maxInstallments requires CARD in methods` | O parcelamento só vale com `CARD` em `methods`. |
| `Total below minimum for 3x (R$10 per installment)` | Cada parcela precisa ser de pelo menos R$ 10,00. |
| `Up sell product must be active` | O produto de `upSellProductId` foi arquivado. Ele também não pode ter `cycle`. |
| `returnUrl must use http or https only` | A URL precisa começar com `http://` ou `https://`. Vale também para `completionUrl`. |
