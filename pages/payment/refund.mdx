---
title: Reembolsar um Checkout
openapi: 'POST /checkouts/refund'
---

Reembolsa o valor total de um pagamento de checkout, por Pix ou cartão.

<Card horizontal>
  Requer a permissão `REFUND:CREATE`.
</Card>

<Card title="Entenda os reembolsos" icon="rotate-left" href="/pages/vender/reembolsos" horizontal>
  Regras, status do checkout, upsell, cartão já liquidado, webhooks e todas as mensagens de erro.
</Card>

O `id` aceita:

| Prefixo | O que é |
|---|---|
| `bill_` | O checkout. A API reembolsa o pagamento principal dele. |
| `char_`, `pix_char_`, `card_` | Um pagamento do checkout, como o do upsell. |

```json
{
  "id": "bill_abc123xyz",
  "reason": "Pedido cancelado pelo cliente."
}
```

`reason` é opcional, com até 500 caracteres.

## Erros desta rota

| Mensagem em `error` | Quando acontece |
|---|---|
| `Identificador inválido para esta rota. Use bill_, char_, pix_char_ ou card_.` | Prefixo de `id` não aceito. |
| `Use a rota /v2/payment-links/refund para reembolsar pagamentos de links de pagamento.` | O `id` é de um link de pagamento ou de um pagamento de link. |
| `Use a rota /v2/transparents/refund para reembolsar cobranças transparentes.` | O `id` é de uma cobrança do checkout transparente. |
| `Cobranças de assinatura não podem ser reembolsadas pela API v2.` | O `id` é de uma assinatura. |

As demais mensagens, como saldo insuficiente ou cobrança em disputa, estão em [Reembolsos](/pages/vender/reembolsos#mensagens-de-erro).
