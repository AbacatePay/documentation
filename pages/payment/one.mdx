---
title: 'Buscar um Checkout'
openapi: "GET /checkouts/get"
---

Retorna os dados completos de um checkout pelo seu `id`.

<Card horizontal>
  Requer a permissão `CHECKOUT:READ`.
</Card>

Use este endpoint para verificar o `status` de uma cobrança após o cliente retornar ao seu site, ou ao receber um [webhook](/pages/webhooks) de pagamento.

Informe ao menos um entre `id`, `externalId` e `customerId`. Sem nenhum deles, a API retorna `Provide id, externalId or customerId`.

<Warning>
  Checkouts de assinatura (`frequency: SUBSCRIPTION`) não são retornados por esta rota. Use [Buscar checkout de assinatura](/pages/subscriptions/checkouts-get). Um `id` de checkout de assinatura retorna `This is a subscription checkout. Use /v2/subscriptions/checkouts/get`.
</Warning>

**Valores de `status`:**

| Valor | Significado |
|-------|-------------|
| `PENDING` | Aguardando pagamento |
| `PAID` | Pago com sucesso |
| `EXPIRED` | Expirado sem pagamento |
| `CANCELLED` | Cancelado |
| `REFUNDED` | Reembolsado |
