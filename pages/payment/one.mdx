---
title: 'Buscar um Checkout'
openapi: "GET /checkouts/get"
---

Retorna um checkout pelo `id`, pelo `externalId` ou pelo `customerId`. Use para conferir o `status` quando o cliente volta ao seu site ou quando chega um [webhook](/pages/notificacoes/webhooks).

<Card horizontal>
  Requer a permissão `CHECKOUT:READ`.
</Card>

<Card title="Entenda o checkout" icon="book-open" href="/pages/cobrar/checkout#status-do-checkout" horizontal>
  O que significa cada status, quando `paidAmount` é preenchido e o que muda com o upsell.
</Card>

**Exemplo:**
```bash
curl "https://api.abacatepay.com/v2/checkouts/get?id=bill_abc123xyz" \
  -H "Authorization: Bearer SUA_CHAVE"
```

## Erros

| Erro | Motivo |
|---|---|
| `Provide id, externalId or customerId` | Nenhum dos três parâmetros foi enviado. |
| `Billing not found` | Não existe checkout de pagamento único com esse valor na sua loja. Links de pagamento ficam em [Buscar um link de pagamento](/pages/payment-links/one). |
| `This is a subscription checkout. Use /v2/subscriptions/checkouts/get` | O `id` é de um checkout de assinatura. Use [Buscar checkout de assinatura](/pages/subscriptions/checkouts-get). |
