<Card horizontal>
  Requer a permissão `TRANSPARENT:CREATE`.
</Card>

Cria um boleto no checkout transparente. A resposta traz a página do boleto (`url`), o código de barras (`barCode`), a linha digitável (`identificationNumber`) e o Pix do boleto (`brCode` e `brCodeBase64`). Para Pix, veja [Criar cobrança Pix](/pages/transparents/create).

<Card title="Entenda o boleto" icon="barcode" href="/pages/pagamentos/boleto" horizontal>
  Valor mínimo, vencimento, Pix no boleto, status e como testar.
</Card>

Juros e multa por atraso estão em [Juros e multa no boleto](/pages/pagamentos/juros-e-multa-boleto).

**Exemplo mínimo** (vence em 3 dias úteis):

```json
{
  "method": "BOLETO",
  "data": {
    "amount": 25000,
    "customer": {
      "name": "Mariana Costa",
      "taxId": "987.654.321-00"
    }
  }
}
```

**Exemplo com vencimento, juros e multa:**

```json
{
  "method": "BOLETO",
  "data": {
    "amount": 5000,
    "dueDate": "2026-12-15",
    "description": "Fatura de dezembro",
    "externalId": "fatura-456",
    "customer": {
      "name": "Mariana Costa",
      "taxId": "987.654.321-00",
      "email": "mariana.costa@empresa.com.br",
      "cellphone": "(21) 99876-5432"
    },
    "interest": { "value": 100 },
    "fine": { "value": 1000, "type": "FIXED" },
    "metadata": { "faturaId": "fatura-456" }
  }
}
```

## Erros

| Mensagem | Causa |
|---|---|
| `O valor mínimo para boleto é R$ 3,00 (300 centavos)` | `amount` menor que `300`. |
| `dueDate cannot be in the past` | `dueDate` antes de hoje (horário de Brasília). |
| `dueDate cannot be more than 365 days in the future` | `dueDate` mais de 365 dias à frente. |
| `dueDate must be a valid date in YYYY-MM-DD format` | `dueDate` fora do formato `AAAA-MM-DD`. |
