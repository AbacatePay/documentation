O **checkout transparente** permite receber pagamentos diretamente no seu site ou app — sem redirecionar o cliente para outra página. Suporta **PIX**, **Boleto** e **Cartão de crédito**.

## Métodos disponíveis

| `method` | Descrição                                                                     |
| -------- | ----------------------------------------------------------------------------- |
| `PIX`    | Gera um QR Code e código copia e cola instantâneos                            |
| `BOLETO` | Gera um boleto bancário com PIX alternativo incluído                          |
| `CARD`   | Cobra cartão de crédito, à vista ou em até 12x, com o formulário do abacatepay.js |

Todos os métodos usam o mesmo endpoint: `POST /v2/transparents/create`.

## Parâmetros UTM (`data.utm`)

Objeto opcional em `data` para **`PIX`** e **`BOLETO`**:

| Campo          | Tipo     | Descrição          |
| -------------- | -------- | ------------------ |
| `utm`          | objeto   | Opcional em `data` |
| `utm.source`   | `string` | Opcional           |
| `utm.medium`   | `string` | Opcional           |
| `utm.campaign` | `string` | Opcional           |
| `utm.term`     | `string` | Opcional           |
| `utm.content`  | `string` | Opcional           |

Quando há valores enviados, podem ser **vistos no dashboard**. Metadados de campanha — **não** mudam valores, datas ou regras de cobrança.

Exemplos completos para copiar e colar: [Criar cobrança PIX](/pages/transparents/create) e [Criar cobrança Boleto](/pages/transparents/boleto).

## Receber via PIX

Use `POST /v2/transparents/create`. A API devolve o QR Code em imagem (`brCodeBase64`) e o código copia e cola (`brCode`).

<Video id="https://youtu.be/hwsKTG2M5M8" title="Cobrança PIX - AbacatePay" />

O vídeo também está em [PIX](/pages/videos/pix).

<Card title="Campos obrigatórios" horizontal>
  Só `data.amount` é obrigatório (valor em centavos). Envie `method: "PIX"`.
</Card>

**Exemplo de requisição:**

```json
POST /v2/transparents/create
{
  "method": "PIX",
  "data": {
    "amount": 10000,
    "description": "Cobrança PIX no checkout transparente",
    "expiresIn": 3600,
    "customer": {
      "name": "Daniel Lima",
      "email": "daniel_lima@abacatepay.com",
      "taxId": "111.444.777-35",
      "cellphone": "(11) 4002-8922"
    },
    "metadata": {
      "pedidoId": "pedido-123"
    }
  }
}
```

**Exemplo de resposta:**

```json
{
  "data": {
    "id": "pix_char_abc123xyz",
    "amount": 10000,
    "status": "PENDING",
    "devMode": false,
    "brCode": "00020160014BR.GOV.BCB.PIX070503***6304ABCD",
    "brCodeBase64": "data:image/png;base64,iVBORw0KG...",
    "platformFee": 100,
    "receiptUrl": null,

      "pedidoId": "pedido-123"
    }
  },

  "error": null

```

<Tip title="Usando a resposta" horizontal>
  Use `brCodeBase64` para exibir a imagem do QR Code ou `brCode` (copia e cola) para enviar por WhatsApp/Telegram ou
  integrar no seu checkout.
</Tip>

## Receber via Boleto

Use `POST /v2/transparents/create` com `method: "BOLETO"`. A API devolve a linha digitável (`barCode`), uma URL para visualização e impressão do boleto (`url`), e um código PIX alternativo para a mesma cobrança.

<Card title="Campos obrigatórios" horizontal>
  `data.amount` e `data.customer` (com `name` e `taxId`) são obrigatórios para boleto.
</Card>

Use `data.dueDate` (`YYYY-MM-DD`) para definir a data de vencimento. Se omitido, o padrão é **3 dias úteis**. Não pode ser data no passado; máximo de 365 dias no futuro. A resposta expõe `expiresAt` (ISO datetime no fim do dia do `dueDate`).

**Exemplo de requisição:**

```json
POST /v2/transparents/create
{
  "method": "BOLETO",
  "data": {
    "amount": 5000,
    "dueDate": "2026-08-15",
    "description": "Fatura de serviço mensal",
    "customer": {
      "name": "Mariana Costa",
      "taxId": "987.654.321-00",
      "email": "mariana.costa@empresa.com.br",
      "cellphone": "(21) 99876-5432"
    },
    "metadata": {
      "faturaId": "fatura-456",
      "plano": "pro"
    }
  }
}
```

**Exemplo de resposta:**

## Receber via Cartão

O cartão tem uma etapa a mais que PIX e Boleto, porque o número do cartão não pode passar pelo seu servidor:

1. No navegador, o [abacatepay.js](/pages/transparents/abacatepay-js) mostra o formulário de cartão, usando a sua [chave pública](/pages/transparents/public-key), e gera um token `ctok_`.
2. O seu backend chama `POST /v2/transparents/create` com `method: "CARD"`, o token e os dados do cliente.
3. A resposta traz o `cardToken`, que permite [cobrar o mesmo cartão de novo](/pages/guides/cartao-salvo) sem o cliente digitar nada.

<Card title="Campos obrigatórios" horizontal>
  `data.amount`, `data.customer` (com `name`, `email`, `taxId` e `cellphone`) e o cartão: `data.token` **ou** `data.cardToken`.
</Card>

**Exemplo de requisição:**

```json
POST /v2/transparents/create
{
  "method": "CARD",
  "data": {
    "amount": 10000,
    "token": "ctok_9fK2mQ7xLp4vR8sT1wYz3nBc",
    "customer": {
      "name": "Maria Silva",
      "email": "maria@exemplo.com",
      "taxId": "529.982.247-25",
      "cellphone": "(11) 99999-9999"
    }
  }
}
```

**Exemplo de resposta:**

```json
{
  "data": {
    "id": "card_Wk3aD8sPq1XyZ7mN2bVc4LtR",
    "amount": 10000,
    "status": "APPROVED",
    "devMode": true,
    "cardToken": "dev_card_4242",
    "brand": "VISA",
    "lastFour": "4242",
    "receiptUrl": null,
    "createdAt": "2026-10-12T14:20:31.512Z",
    "updatedAt": "2026-10-12T14:20:31.512Z",
    "metadata": {}
  },
  "success": true,
  "error": null
}
```

<Tip title="Comece pelo passo a passo" horizontal>
  O [passo a passo do checkout transparente](/pages/guides/cartao-transparente) tem um projeto completo (página + backend) para copiar e rodar no Dev mode. Todos os campos estão em [Criar cobrança Cartão](/pages/transparents/card).
</Tip>

## Comprovante

<Video id="https://youtu.be/TwEArVdl-SE" title="Comprovante - AbacatePay" />

Depois que o pagamento confirma, `receiptUrl` traz o link do comprovante. No dashboard, o botão **Ver comprovante** abre o mesmo recibo. O vídeo também está em [Comprovante](/pages/videos/comprovante).

## Ideias de uso

- **PIX no checkout próprio:** exiba o QR Code na sua página e mantenha o cliente no seu site.
- **Boleto por e-mail:** envie `url` ou `barCode` por e-mail ou WhatsApp.
- **Boleto + PIX:** ofereça os dois métodos na mesma tela — o cliente escolhe como pagar.
- **Cartão no checkout transparente:** o cliente digita o cartão na sua página, sem redirecionamento.
- **Recompra com um clique:** guarde o `cardToken` da primeira compra e cobre o mesmo cartão nas próximas.
