<Card horizontal>
  Requer a permissão `TRANSPARENT:CREATE`.
</Card>

Cria uma cobrança Pix no checkout transparente e devolve o QR Code (`brCodeBase64`) e o código copia e cola (`brCode`). Para boleto, veja [Criar cobrança Boleto](/pages/transparents/boleto); para cartão, [Criar cobrança Cartão](/pages/transparents/card).

<Card title="Entenda o Pix" icon="qrcode" href="/pages/pagamentos/pix" horizontal>
  Validade do QR Code, valor mínimo, trava de CPF/CNPJ, status, webhooks e como testar.
</Card>

**Exemplo mínimo:**

```json
{
  "method": "PIX",
  "data": {
    "amount": 10000
  }
}
```

**Exemplo completo:**

```json
{
  "method": "PIX",
  "data": {
    "amount": 10000,
    "description": "Pedido 123",
    "expiresIn": 3600,
    "externalId": "pedido-123",
    "ensureSameTaxId": true,
    "customer": {
      "name": "Daniel Lima",
      "email": "daniel_lima@abacatepay.com",
      "taxId": "111.444.777-35",
      "cellphone": "(11) 4002-8922"
    },
    "metadata": { "pedidoId": "pedido-123" },
    "utm": { "source": "newsletter", "medium": "email", "campaign": "lancamento" }
  }
}
```

**Exemplo com split para [subcontas](/pages/dinheiro/subcontas-e-split):**

```json
{
  "method": "PIX",
  "data": {
    "amount": 10000,
    "splits": [
      { "subAccountId": "sacc_9f8Kq2LmX4vTzR7pWn3bYc1H", "amount": 7000 },
      { "subAccountId": "sacc_2Hq7Lm9XpR4vTzK8sWn3bYc5", "amount": 1500 }
    ]
  }
}
```

**Resposta:**

```json
{
  "data": {
    "id": "pix_char_abc123xyz",
    "amount": 10000,
    "status": "PENDING",
    "devMode": false,
    "brCode": "00020101021226950014br.gov.bcb.pix...",
    "brCodeBase64": "data:image/png;base64,iVBORw0KG...",
    "platformFee": 80,
    "receiptUrl": null,
    "createdAt": "2026-11-10T18:38:28.573Z",
    "updatedAt": "2026-11-10T18:38:28.573Z",
    "expiresAt": "2026-11-10T19:38:28.573Z",
    "metadata": { "pedidoId": "pedido-123" }
  },
  "success": true,
  "error": null
}
```

## Erros

| Mensagem | Causa |
|---|---|
| `ensureSameTaxId requires a customer with taxId` | `ensureSameTaxId: true` sem `customer.taxId`. |
| `ensureSameTaxId is not supported by the current PIX provider` | A trava de CPF/CNPJ não está disponível na sua conta. |
| `expiresIn must be at least 300 seconds` | `expiresIn` menor que 300. |
| `Disallowed character in description: ...` | A descrição tem emoji ou outro caractere não permitido. A mensagem diz qual. |
| `PIX is not available for this store` | O Pix não está liberado na sua conta. |
| `Split para subcontas não está habilitado para esta loja` | `splits` sem as subcontas liberadas. |
| `Subconta repetida no split` | A mesma subconta aparece duas vezes em `splits`. |
| `A soma dos splits passa do valor líquido da cobrança` | As partes somam mais que o valor menos a taxa. |
