---
title: 'Simular Pagamento'
openapi: 'POST /transparents/simulate-payment'
---

<Card horizontal>
  Requer a permissão `TRANSPARENT:CREATE`. Só no Modo Teste.
</Card>

Marca como paga uma cobrança Pix do checkout transparente, para testar o fluxo sem fazer um Pix de verdade. A cobrança passa para `PAID` e o webhook `transparent.completed` é disparado.

<Card title="Entenda o Pix" icon="qrcode" href="/pages/pagamentos/pix#testar-no-modo-teste" horizontal>
  Como testar o Pix no checkout, no link de pagamento e no checkout transparente.
</Card>

```bash
curl -X POST "https://api.abacatepay.com/v2/transparents/simulate-payment?id=pix_char_abc123xyz" \
  -H "Authorization: Bearer $ABACATEPAY_API_KEY"
```

## Erros

| Mensagem | Causa |
|---|---|
| `Simulate payment is only available in dev mode` | A chave é de produção. Use uma chave do [Modo Teste](/pages/comecar/modo-teste). |
| `Pix QR Code not found` | O `id` não existe, a cobrança não está mais pendente ou o `id` é de um boleto ou de um cartão. |
