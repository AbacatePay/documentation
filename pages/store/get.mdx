---
title: 'Obter detalhes da loja'
openapi: "GET /stores/get"
---

Retorna o ID, o nome e o saldo da sua loja.

<Card horizontal>
  Requer a permissão `STORE:READ`.
</Card>

<Card title="Entenda o saldo" icon="wallet" href="/pages/dinheiro/saldo-e-extrato" horizontal>
  Saldo disponível, pendente e bloqueado, antecipação em processamento e quando cada pagamento fica disponível.
</Card>

**Exemplo:**
```bash
curl "https://api.abacatepay.com/v2/stores/get" \
  -H "Authorization: Bearer SUA_CHAVE"
```

```json
{
  "data": {
    "id": "store_abc123xyz",
    "name": "Minha Loja",
    "balance": {
      "available": 50000,
      "pending": 10000,
      "blocked": 0,
      "processingAnticipation": 0
    }
  },
  "success": true,
  "error": null
}
```

Os valores de `balance` são em centavos e somam o saldo de Pix e boleto com o de cartão.

**Erros comuns:**

| `error` | Motivo |
|---|---|
| `Store not found` | A loja da chave não foi encontrada |
| `Bank account not found` | A loja ainda não tem conta de saldo |
