Ir para produção tem dois passos independentes: ter a [conta verificada](/pages/comecar/conta-e-verificacao), o que se faz uma vez só, e trocar a chave de API do Modo Teste pela de produção no seu sistema. Os dois precisam estar prontos antes de processar pagamentos reais.

## Checklist

## Depois da aprovação

Quando a conta é aprovada, você recebe um e-mail. Então:

1. Desligue o **Modo Teste (Sandbox)** no dashboard e crie uma chave de produção em **Integração → API → Nova chave**. Veja [Chaves de API](/pages/comecar/chaves-de-api).
2. Troque, no seu sistema, a chave do Modo Teste pela de produção. A URL da API é a mesma.
3. Crie os webhooks de novo com o Modo Teste desligado. Os webhooks do Modo Teste não recebem eventos reais.
4. Faça uma venda real de valor baixo para confirmar que está tudo funcionando.
