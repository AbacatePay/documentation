---
title: Buscar PIX
openapi: 'GET /pix/get'
---

Retorna os dados de uma transação PIX pelo seu `id`.

<Card horizontal>
  Requer a permissão `WITHDRAW:READ`.
</Card>

Use para acompanhar o `status` de um envio após criar a transação.

**Valores de `status`:**

| Valor | Significado |
|-------|-------------|
| `COMPLETE` | Envio aceito pelo provedor. Todo PIX enviado já é criado com esse status. |
| `FAILED` | O provedor recusou o envio depois de aceito. O valor volta para o seu saldo. |

Como um envio `COMPLETE` ainda pode passar para `FAILED`, prefira confirmar o resultado pelos webhooks `transfer.completed` e `transfer.failed` (veja [Transferências](/pages/webhooks/events/transfers)).
