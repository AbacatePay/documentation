---
title: Enviar PIX
openapi: 'POST /pix/send'
---

Envia dinheiro para qualquer chave PIX de terceiros — fornecedores, parceiros ou colaboradores.

<Card horizontal>
  Requer a permissão `WITHDRAW:CREATE`.
</Card>

<Note>
**PIX vs Saques:** use **PIX** para enviar a chaves de terceiros. Para sacar para a sua própria chave use [Saques](/pages/payouts/create).
</Note>

<Warning>
  O destino é aninhado em `pix`, com as chaves `key` e `type`. Enviar
  `pixKey`/`pixKeyType` no topo falha com `Property 'pix' is missing`, e
  aninhar com esses nomes falha com `Property 'pix.type' is missing`.
</Warning>

**Formato aceito pela API:**
```json
{
  "amount": 10000,
  "description": "Pagamento fornecedor #42",
  "externalId": "pix-123",
  "pix": {
    "key": "contato@fornecedor.com",
    "type": "EMAIL"
  }
}
```

**Tipos de chave PIX aceitos:**

| `pix.type` | Exemplo |
|--------------|---------|
| `CPF` | `12345678901` |
| `CNPJ` | `12345678000190` |
| `PHONE` | `11987654321` |
| `EMAIL` | `contato@exemplo.com` |
| `RANDOM` | UUID aleatório |
| `BR_CODE` | Código completo do QR |

<Warning title="A taxa sai do valor enviado" horizontal>
A taxa da plataforma é descontada do `amount`: com `"amount": 10000` e taxa de R$ 0,80, o destinatário recebe R$ 99,20. Para pagar exatamente R$ 100,00 a um fornecedor, envie o valor somado à taxa (`"amount": 10080`). O seu saldo precisa cobrir o `amount` inteiro.
</Warning>

<Note>
O envio é criado com `status: "COMPLETE"`, que significa que o provedor aceitou o PIX. Se o provedor recusar depois, o status passa a `FAILED` e o valor volta para o seu saldo. Como `externalId` é obrigatório aqui, o resultado chega pelos webhooks `transfer.completed` e `transfer.failed`.
</Note>

<Tip title="Limites" horizontal>
Valor mínimo: R$ 1,00. O processamento é instantâneo e disponível 24/7.
</Tip>
