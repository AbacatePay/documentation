---
title: 'Criar checkout de assinatura'
openapi: "POST /subscriptions/create"
---

Cria um checkout de assinatura (`bill_...`). Depois que o cliente paga na `url` da resposta, a assinatura (`subs_...`) passa a existir.

<Card horizontal>
  Requer a permissão `SUBSCRIPTION:CREATE`.
</Card>

<Card title="Entenda as assinaturas" icon="rotate" href="/pages/cobrar/assinaturas" horizontal>
  Ciclos, retentativas, teste grátis, cupom, troca de plano e cancelamento.
</Card>

**Exemplo no cartão:**
```json
{
  "items": [
    { "id": "prod_abc123xyz", "quantity": 1 }
  ],
  "customerId": "cust_abc123xyz",
  "externalId": "assinatura-123",
  "completionUrl": "https://seusite.com/sucesso",
  "methods": ["CARD"],
  "retryPolicy": {
    "maxRetry": 3,
    "retryEvery": 2
  }
}
```

**Exemplo no [Pix Automático](/pages/cobrar/pix-automatico):**
```json
{
  "items": [
    { "id": "prod_abc123xyz", "quantity": 1 }
  ],
  "customerId": "cust_abc123xyz",
  "methods": ["PIX"]
}
```

## Erros

| `error` | Causa |
|---|---|
| `No products found` | Nenhum produto de `items` foi encontrado. |
| `No subscription product with cycle found for billing` | Nenhum produto de `items` tem `cycle`. |
| `Subscription checkout: every item must have a billing cycle` | Algum produto de `items` não tem `cycle`. |
| `All products in a subscription checkout must share the same billing cycle` | Os produtos de `items` têm ciclos diferentes. |
| `Multiple products are not available for subscription checkouts on this store` | Mais de um produto em `items`, sem a liberação na conta. |
| `PIX Automático is not available for this store` | `PIX` em `methods`, sem o Pix Automático liberado. |
| `Subscription is not available for this store` | A conta não tem assinaturas liberadas em produção. |
| `Subscription checkouts do not support card installments` | `card.maxInstallments` maior que `1`. |
| `card.passFeesToCustomer is not available for subscriptions` | `card.passFeesToCustomer: true`. |
