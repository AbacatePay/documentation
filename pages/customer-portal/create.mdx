---
title: 'Criar um link do portal'
openapi: "POST /customer-portal/create"
---

Gera o link do portal do cliente para um cliente e um checkout que ele pagou. Chamar de novo com os mesmos IDs devolve o mesmo link.

<Card horizontal>
  Requer uma destas permissões: `CHECKOUT:CREATE`, `SUBSCRIPTION:CREATE` ou `CUSTOMER:CREATE`.
</Card>

<Card title="Entenda o portal do cliente" icon="book-open" href="/pages/vender/portal-do-cliente" horizontal>
  O que o cliente pode fazer, como ele entra e os webhooks que você recebe.
</Card>

`checkoutId` aceita o `id` de um checkout, de um link de pagamento ou de um checkout de assinatura.

**Exemplo:**
```json
{
  "customerId": "cust_abc123xyz",
  "checkoutId": "bill_abc123xyz"
}
```

## Erros

| Erro | Motivo |
|---|---|
| `Checkout not found` | O `checkoutId` não existe na sua loja, ou é do outro ambiente (Modo Teste ou produção). |
| `Customer not found` | O `customerId` não existe ou foi removido. |
| `Customer has no email to receive the access code` | O cliente não tem e-mail. O código de acesso vai por e-mail. |
| `Customer has no payment for this checkout` | O cliente ainda não pagou esse checkout. Em assinatura, ainda não tem assinatura criada nele. |
