A **AbacatePay CLI** é a ferramenta oficial de linha de comando para testar sua integração com a AbacatePay direto do terminal.

Com ela você recebe na sua máquina os webhooks da sua conta em dev mode e simula o pagamento de cobranças — sem precisar expor sua aplicação local na internet.

## Instalação

### Script de instalação (Linux e macOS)

```bash
curl -fsSL https://abacatepay.com/install.sh | sh
```

Baixa o binário `abacatepay` do último release publicado, valida o checksum e instala em `/usr/local/bin`. Para instalar em outro diretório, use `ABACATEPAY_INSTALL_DIR`:

```bash
curl -fsSL https://abacatepay.com/install.sh | ABACATEPAY_INSTALL_DIR="$HOME/.local/bin" sh
```

### Go

```bash
go install github.com/AbacatePay/abacatepay-cli/cmd/abacatepay@latest
```

<Note>
Use o caminho `.../cmd/abacatepay`. O comando `go install github.com/AbacatePay/abacatepay-cli@latest` também funciona, mas instala o binário com o nome `abacatepay-cli`.
</Note>

### Binários prontos

Os [releases no GitHub](https://github.com/AbacatePay/abacatepay-cli/releases) publicam binários para Linux, macOS e Windows, nas arquiteturas `amd64` e `arm64`.

**Verificar instalação:**

```bash
abacatepay --version
```

## Primeiros passos

<Steps>
  <Step title="Autentique-se">
    ```bash
    abacatepay login
    ```
    O navegador abrirá para você aprovar o acesso da CLI na sua conta.
  </Step>

  <Step title="Inicie o listener">
    ```bash
    abacatepay listen --forward-to http://localhost:3000/webhooks/abacatepay
    ```
    Se você rodar apenas `abacatepay listen`, a CLI pergunta para qual URL encaminhar os eventos.
  </Step>

  <Step title="Crie uma cobrança de teste">
    Crie uma [cobrança transparente](/pages/transparents/create) com uma chave de dev mode — pela API ou por um dos [SDKs](/pages/sdks/sdks) — e anote o `id` retornado.
  </Step>

  <Step title="Simule o pagamento">
    Em outro terminal:
    ```bash
    abacatepay payments simulate <charge-id>
    ```
    O webhook do pagamento aparece no terminal do `listen` e é encaminhado para sua aplicação.
  </Step>
</Steps>

## Escopo atual

A CLI cobre o ciclo de desenvolvimento local com a API v2:

- login e logout;
- receber webhooks de dev mode e encaminhar para sua aplicação;
- simular o pagamento de cobranças transparentes em dev mode;
- atualizar a própria CLI.

<Info>
A CLI só recebe eventos de dev mode. Eventos de produção nunca são enviados para a CLI.
</Info>
