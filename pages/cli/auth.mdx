Comandos para autenticar a CLI na sua conta AbacatePay.

---

### `abacatepay login`

Autentica a CLI. Sem flags, abre o navegador para você aprovar o acesso; com `--key`, valida a API key informada direto.

```bash
abacatepay login [flags]
```

| Flag | Descrição | Padrão |
|------|-----------|--------|
| `--name` | Nome do perfil onde a credencial será salva | `default` |
| `--key` | API key da AbacatePay (pula o fluxo pelo navegador) | - |

Alias: `abacatepay signin`.

**Exemplos:**

```bash
# Login pelo navegador
abacatepay login

# Login com API key (útil em CI ou máquinas sem navegador)
abacatepay login --key "sua_api_key"

# Salvar em um perfil nomeado
abacatepay login --name loja-teste --key "sua_api_key"
```

<Info>
Se o navegador não abrir sozinho, a CLI mostra o link de aprovação no terminal. Abra-o em qualquer navegador logado na sua conta e a CLI continua sozinha depois que você aprovar.
</Info>

A credencial é validada contra a API antes de ser salva. O perfil usado no login passa a ser o **perfil ativo**.

Enquanto aguarda a aprovação (ou valida a chave), a CLI mostra um spinner. No fim, mostra o resultado:

<CodeGroup>
```text Sucesso
🥑 Authenticated
Profile: default
User: Minha Loja
```

```text Erro
⚠️  Error: invalid API key
```
</CodeGroup>

Com `--key`, o título é `Welcome back`.

<Note>
O ambiente (dev mode ou produção) é definido pela API key, não por uma flag da CLI. Para testar com `listen` e `payments simulate`, use uma chave de dev mode.
</Note>

---

### `abacatepay logout`

Remove a credencial do perfil ativo.

```bash
abacatepay logout
```

Alias: `abacatepay signout`.

```text
🥑 Signed out successfully
Profile: default
```

Se houver outros perfis salvos, um deles passa a ser o perfil ativo. Se não houver, você precisa rodar `abacatepay login` de novo para usar os outros comandos.

---

## Perfis

Cada login fica salvo em um perfil. Use `--name` para manter mais de uma conta na mesma máquina:

```bash
abacatepay login --name loja-a --key "chave_loja_a"
abacatepay login --name loja-b --key "chave_loja_b"
```

Os comandos sempre usam o **perfil ativo**, que é o do último login. Para voltar a usar outro perfil, faça login nele de novo:

```bash
abacatepay login --name loja-a --key "chave_loja_a"
```

<Tip>
Fazer login em um perfil que já existe substitui a credencial salva nele.
</Tip>

As credenciais ficam no keyring do sistema operacional. Veja [Configuração](./flags#credenciais) para detalhes.
