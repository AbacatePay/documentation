### `abacatepay payments simulate`

Simula o pagamento de uma [cobrança transparente](/pages/transparents/reference) criada com uma API key de dev mode.

```bash
abacatepay payments simulate <charge-id>
```

Alias: `abacatepay payments simulate-payment`.

```bash
abacatepay payments simulate pix_char_123456
```

Por baixo, o comando chama a mesma rota documentada em [Simular pagamento](/pages/transparents/simulate-payment):

```http
POST /v2/transparents/simulate-payment?id=<charge-id>
```

```text
🥑 Payment Simulated
ID: pix_char_123456
Status: PAID
DevMode: true
```

Com `-v`, a CLI também mostra a requisição e a resposta completas da API.

<Info>
Depois da simulação, a cobrança passa para pago e os webhooks da sua conta são disparados normalmente — inclusive para quem estiver rodando `abacatepay listen`.
</Info>

<Warning>
Só funciona para cobranças em dev mode. Em produção, o pagamento precisa acontecer pelo fluxo real.
</Warning>

---

### Criar a cobrança

A CLI não cria cobranças. Crie a cobrança transparente pela [API](/pages/transparents/create) ou por um dos [SDKs](/pages/sdks/sdks), usando a mesma chave de dev mode, e passe o `id` retornado (ex.: `pix_char_abc123xyz`) para o `simulate`.
