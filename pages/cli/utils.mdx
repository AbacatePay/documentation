### `abacatepay upgrade`

Atualiza a CLI para a versão mais recente publicada nos [releases do GitHub](https://github.com/AbacatePay/abacatepay-cli/releases), substituindo o binário atual.

```bash
abacatepay upgrade
```

<CodeGroup>
```json Atualização disponível
{
  "title": "Update complete ✨",
  "fields": {
    "Version": "0.1.4"
  }
}
```

```json Já atualizado
{
  "title": "Already up to date",
  "fields": {
    "Version": "0.1.4"
  }
}
```
</CodeGroup>

<Note>
Se a CLI foi instalada em um diretório do sistema (como `/usr/local/bin`), pode ser preciso rodar com `sudo`. Se você instalou com `go install`, também pode atualizar rodando o mesmo comando de instalação de novo.
</Note>

---

### `abacatepay --version`

Mostra a versão instalada.

```bash
abacatepay --version
```
