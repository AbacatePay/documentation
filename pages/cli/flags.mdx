## Flags globais

Flags disponíveis em todos os comandos:

| Flag | Alias | Tipo | Padrão | Descrição |
|------|-------|------|--------|-----------|
| `--verbose` | `-v` | bool | `false` | Habilita logging detalhado (nível debug) e mostra requisições e respostas da API |
| `--version` | - | bool | - | Mostra a versão instalada |
| `--help` | `-h` | bool | - | Mostra a ajuda do comando |

<Note>
A flag `--local` (`-l`) está obsoleta e não tem efeito. O ambiente (dev mode ou produção) é definido pela API key usada no login.
</Note>

## Saída no terminal

A CLI é 100% TUI. Enquanto um comando roda, ela mostra um spinner com o que está fazendo; no fim, o spinner dá lugar ao resultado:

```text
⠋ Simulating payment...
```

```text
🥑 Payment Simulated
ID: pix_char_abc123xyz
Status: PAID
DevMode: true
```

Erros aparecem no mesmo lugar, e o processo sai com código `1`:

```text
⚠️  Error: no active profile found
```

O `listen` abre um painel interativo próprio. Veja [Painel interativo](./webhooks#painel-interativo).

### Fora de um terminal

Quando a saída não é um terminal (pipe, CI), a CLI não anima nada: imprime a mensagem de progresso uma vez e o resultado em linhas simples, com o mesmo conteúdo.

<Tip>
Em scripts, use o código de saída do comando (`0` para sucesso, `1` para erro) em vez de interpretar o texto, que pode mudar entre versões.
</Tip>

## Credenciais

As credenciais de cada perfil ficam no keyring nativo do sistema:

- **macOS**: Keychain
- **Windows**: Credential Manager
- **Linux**: Secret Service (gnome-keyring ou KWallet)

Quando nenhum keyring do sistema está disponível (ex.: servidor Linux sem sessão gráfica ou container), a CLI salva as credenciais em um arquivo criptografado em `~/.abacatepay/keyring/`.

## Logs

Os logs ficam em `~/.abacatepay/logs/`:

- **abacatepay.log** — log geral da CLI (JSON)
- **transactions.log** — webhooks recebidos e encaminhados pelo `listen` (veja [Histórico local](./webhooks#histórico-local))

Rotação automática: 10 MB por arquivo, 5 backups e 30 dias de retenção.

```bash
# Ver erros
jq 'select(.level=="ERROR")' ~/.abacatepay/logs/abacatepay.log

# Tempo médio de encaminhamento (ms)
jq 'select(.msg=="webhook_forwarded") | .duration_ms' ~/.abacatepay/logs/transactions.log | jq -s 'add/length'
```
